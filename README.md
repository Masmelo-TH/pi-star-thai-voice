# เสียงประกาศภาษาไทยสำหรับ Pi-Star / ircDDBGateway (D-Star)

แพ็กเสียงประกาศ **D-Star ภาษาไทย** (เสียงคนจริง) สำหรับ hotspot ที่ใช้ **Pi-Star + ircDDBGateway**
แทนเสียงอังกฤษเดิมของการประกาศ **สถานะลิงก์ reflector** (เชื่อมต่อ / กำลังเชื่อมต่อ / ไม่ได้เชื่อมต่อ
+ สะกดชื่อ reflector และ callsign) — **การขานเวลา (time) ยังคงเป็นภาษาอังกฤษเดิม ไม่ถูกแตะ**
(เพราะรูปแบบ 12 ชม.+AM/PM ของ ircDDBGateway ทำให้ลำดับคำไทยฟังไม่เป็นธรรมชาติ)

> บันทึกเสียงโดย **E29WWT** — แก้ชื่อผู้บันทึก/เครดิตได้ตามต้องการ

---

## จะได้ยินอะไร
- เชื่อม REF087 C → *"เชื่อมต่อกับ อาร์ อี เอฟ ศูนย์ แปด เจ็ด ชาลี"* (เสียงไทย)
- ขานเวลา → *"It is ten AM"* (คงเป็นอังกฤษเดิม)

## ต้องมีอะไรบ้าง
- Hotspot ที่รัน **Pi-Star** (มี ircDDBGateway และเปิดใช้ **D-Star**)
- ตั้งภาษา ircDDBGateway เป็น **English_(UK)** = `language=0` (แพ็กนี้ไปแทนช่อง `en_GB`)
- เข้าถึงเครื่องผ่าน **SSH** ได้ (ผู้ใช้ `pi-star`)

## วิธีติดตั้ง (ทำบน Pi ผ่าน SSH — ไม่ต้องใช้ Claude/คอมพิวเตอร์อื่น)
```bash
# 1) SSH เข้า hotspot (เปลี่ยน IP เป็นของเครื่องเพื่อน)
ssh pi-star@192.168.x.x        # รหัสผ่านเริ่มต้น Pi-Star: raspberry

# 2) โหลดแพ็กนี้ลงเครื่อง
cd /tmp
git clone https://github.com/Masmelo-TH/pi-star-thai-voice.git
cd pi-star-thai-voice

# 3) ติดตั้ง (สคริปต์จะสำรองไฟล์อังกฤษเดิมเป็น .orig, ก๊อปไฟล์ไทย, รีสตาร์ตเซอร์วิสให้เอง)
sudo bash install.sh
```
เสร็จแล้วลองเชื่อม reflector เพื่อฟังเสียงไทย

## ย้อนกลับเป็นอังกฤษ
```bash
cd /tmp/pi-star-thai-voice && sudo bash restore.sh
```

## ไฟล์ในแพ็ก
| ไฟล์ | ใช้ทำอะไร |
|------|-----------|
| `voices/en_GB.indx` + `en_GB.ambe` | คำหลัก 44 คำ (0-9, A-Z, alpha/bravo/charlie/delta, linked/linking/notlinked/isbusy) + คีย์ `linkedto`/`linkingto` |
| `install.sh` | ติดตั้ง (สำรอง + ก๊อป + รีสตาร์ต ircddbgateway) |
| `restore.sh` | คืนค่าเสียงอังกฤษจากไฟล์ `.orig` |

## ข้อควรรู้ (สำคัญ)
- แพ็กนี้แทน **เฉพาะเสียงประกาศลิงก์ (main pack `en_GB`)** เท่านั้น — **ไม่แตะการขานเวลา**
  ดังนั้นเสียงเวลาจะยังเป็นภาษาอังกฤษเดิมของเครื่อง
- คีย์ `linkedto`/`linkingto` มีไว้กันบั๊กที่ ircDDBGateway เล่นเลข "2" (คำว่า "two"≈"to" ของฝรั่ง) โผล่เป็น "สอง"
- เสียง "ศูนย์" อาจเพี้ยนเล็กน้อย (ฟังคล้าย "ฉูน") เป็นข้อจำกัดของ D-Star ที่ตัดความถี่เกิน 4kHz
  ทำให้เสียง /s/ (5-8kHz) หายไป — ลดได้แต่ลบไม่หมด
- แพ็กนี้ทำ **เฉพาะฝั่ง D-Star** — ฝั่ง DMR (`/usr/local/etc/DMR_Audio/`) ยังเป็นอังกฤษ
- ถ้ากด**"Apply Changes"** ในหน้าเว็บ Pi-Star แล้วเผลอเปลี่ยนภาษา อาจต้องตั้ง `language=0` ใหม่
  (ไฟล์เสียงจะไม่ถูกเขียนทับ เพราะเว็บไม่ยุ่งกับไฟล์ .ambe/.indx) — ไฟล์ `.orig` ยังอยู่เสมอ
